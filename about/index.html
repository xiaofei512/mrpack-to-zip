About MRPACK to ZIP

MRPACK to ZIP is an independent browser-based utility maintained by xiaofei512. It converts Modrinth .mrpack manifests into Launcher ZIP or Server ZIP output while reporting files the browser could not safely include.

What the Tool Does—and Does Not Do

It does

  • Read modrinth.index.json from a selected MRPACK file.
  • Copy shared and target-specific overrides into a new ZIP.
  • Fetch manifest files and check supported hashes.
  • Report blocked, invalid, unsafe, or mismatched files.

It does not

  • Operate an upload or mod-hosting backend.
  • Guarantee every third-party host permits browser downloads.
  • Bypass hash mismatches or unsafe archive paths.
  • Provide a complete one-click Minecraft server installation.

Evidence and Maintenance Rules

  • Manifest, environment, hash, and override behavior is checked against the Modrinth MRPACK format specification.
  • Browser cross-origin limits are explained using the MDN CORS guide.
  • Safety checks are not weakened to turn a failed or partial conversion into success.
  • Claims tied to a pack version are dated so later changes can be distinguished.
