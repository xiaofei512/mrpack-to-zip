How to Convert MRPACK to ZIP

Use this guide when you have a Modrinth .mrpack file but need a normal ZIP for launcher import, manual install, or another tool that expects ZIP packages.

Published June 30, 2026

Open the converter

Quick Answer

Open the MRPACK to ZIP Converter, choose Upload File, From URL, or Project ID, keep Launcher ZIP selected, then click Convert file to ZIP. The conversion runs in your browser and downloads a ZIP when it finishes.

Local files are not uploaded. Remote URL and project modes still fetch remote files from your browser, so some files can fail if their host blocks browser downloads.

Option 1: Upload a Local MRPACK File

Choose Upload File when the .mrpack file is already on your computer. This is the most direct path because the browser can read the pack manifest immediately.

  1. Select Upload File.
  2. Drop your .mrpack file onto the upload area or click to browse.
  3. Keep Launcher ZIP selected unless you specifically need server output.
  4. Click Convert file to ZIP.

Option 2: Use a Modrinth Project ID or Slug

Choose Project ID when you want the converter to find the latest usable Modrinth pack file. You can paste a project page URL, a project ID, or a slug such as fabulously-optimized.

This is useful when you know the pack name but do not want to manually hunt for the .mrpack download URL.

Option 3: Paste a Direct MRPACK URL

Choose From URL if you already have a direct link that ends in, or downloads as, a .mrpack file. A normal Modrinth project page is not always a direct file URL, so use Project ID mode for project pages.

After Conversion

When conversion succeeds, download the ZIP and import it into a launcher that accepts ZIP packages, or use it as a manual install base. If the result is partial, read the missing file report before assuming the pack is complete.

  • Missing file: the browser could not download a referenced file.
  • Hash mismatch: the downloaded file did not match the manifest hash.
  • Blocked by CORS: the file host does not allow browser-based downloads.

Next: Choose the Right ZIP Output

For most players, the default Launcher ZIP is the right choice. If you are preparing a server, read Launcher ZIP vs Server ZIP before using the advanced Server ZIP option.
