Launcher ZIP vs Server ZIP for MRPACK Files

The default Launcher ZIP is for player-side imports. Server ZIP is an advanced output that only differs when the MRPACK manifest marks files or overrides as server-specific.

Published June 30, 2026

Open the converter

Short Answer

Use Launcher ZIP unless you are deliberately preparing a Minecraft server. Use Server ZIP only when you understand that it is not a one-click server installer and may still need loader files, startup scripts, Java settings, and manual configuration.

Comparison Table

Output Best for Includes Does not include
Launcher ZIP Launcher imports and manual client installs Files marked for client or both sides, plus shared/client overrides Server runtime setup
Server ZIP Preparing server-compatible pack files Files marked for server or both sides, plus shared/server overrides One-click hosting, server jar, startup scripts, or EULA setup

Launcher ZIP Is the Default for a Reason

Most visitors are trying to import a pack into a launcher or inspect a normal ZIP. For that workflow, Launcher ZIP is the safer default because it follows the client-side files in the pack manifest.

When to Use Server ZIP

Open Advanced and choose Build a Server ZIP instead when you are preparing a server-side file set. A pack such as asguhoserver is a better candidate for this workflow than a purely client-focused optimization pack.

Server ZIP means server-targeted pack files, not a complete server host. You may still need to install the mod loader, accept the EULA, add launch scripts, and configure memory.

Why Do Some ZIPs Look the Same?

Some MRPACK manifests mark many files as usable on both client and server, or they do not include separate server override folders. In those cases, Launcher ZIP and Server ZIP can look very similar.

That does not mean the server option is broken. It means the source pack did not provide much server-specific separation for the converter to apply.

  • asguhoserver: use it as a server-oriented example when testing the advanced Server ZIP path.

Decision Checklist

  • Importing into a launcher? Choose Launcher ZIP.
  • Installing manually for single-player or client use? Choose Launcher ZIP.
  • Preparing files for a server? Try Server ZIP.
  • Expecting a full server installer? This converter is not that tool.
  • Outputs look identical? Check whether the pack actually separates client/server files.
