Privacy

How MRPACK to ZIP Handles Data

Local MRPACK files are read and converted in your browser. The site has no conversion backend, but remote modes contact third-party hosts and the production site uses Google Analytics. The details below separate those paths.

Short Privacy Summary

Local upload mode

Your selected .mrpack file is read in browser memory and is not uploaded to a site conversion server.

Remote modes

Your browser contacts Modrinth or the remote URL host to retrieve pack data and manifest files.

Analytics

Google Analytics receives page and coarse interaction events, including enumerated conversion and task-outcome categories, but the site's custom events omit pack names, URLs, filenames, and file paths.

Saved output

The generated ZIP and optional missing-file report are downloaded through your browser. The site does not keep a server copy.

What Happens During Conversion

Input mode What is read or sent Destination
Upload File The selected MRPACK archive is read in browser memory. No site conversion backend; manifest download URLs are contacted directly by your browser.
Project ID The Modrinth project URL, slug, or ID is used to find a version, then its MRPACK file is fetched. api.modrinth.com, Modrinth's CDN, and hosts listed by the pack manifest.
From URL The direct MRPACK URL and its response are handled by your browser. The URL host and hosts listed by the downloaded pack manifest.
Help email link Clicking the link opens your email app but does not send a message. Only information you choose to put in an email is sent. Your email provider and the maintainer inbox at wuguang425@gmail.com.

Remote services receive normal web request information such as your IP address, browser headers, and the requested URL. Their own policies and server logs apply. Read the Modrinth Privacy Policy when using Project ID mode.

Google Analytics and Microsoft Clarity

The production site loads optional Google Analytics 4 using measurement ID G-PYDQW2NQP0. Google may process page, device, browser, approximate location, and interaction information under the Google Privacy Policy.

The converter's custom events use only these coarse fields:

  • input type: upload, URL, or project;
  • target: Launcher ZIP or Server ZIP;
  • conversion status and a typed failure category;
  • whether the after-test checkpoint was shown, answered Yes or No, or deferred;
  • an enumerated No reason such as launcher rejection, missing files, or download/open failure;
  • a broad file-count bucket such as 1–10 or 11–50.

Custom event parameters do not include the selected filename, pack name, project slug, direct URL, downloaded file path, report contents, or generated ZIP contents. The checkpoint has no free-text field.

Cookies, Browser Storage, and Retention

The converter code does not store pack data in localStorage or sessionStorage, and it does not set its own application cookies. Google Analytics may use cookies or similar browser identifiers. Microsoft Clarity may set _clck and _clsk cookies to associate sessions and improve session analysis. After consent, Clarity may observe visible page content in its session measurements; do not enter sensitive information into the converter. Browser settings or content blockers can limit that analytics storage. Neither service loads until you choose “Allow analytics” in the consent control.

Because there is no conversion backend, the site does not retain uploaded MRPACK files, generated ZIPs, missing-file reports, or remote URLs in a conversion database. Analytics retention is controlled through the site's Google Analytics configuration and Google's policies.

The after-test checkpoint is kept only in the current page's memory. It resets when a new conversion starts or the page reloads. The site does not create a separate feedback database or store the checkpoint in browser storage.

Your Choices

  • Use Upload File mode when you do not want to send a project identifier or direct MRPACK URL to a lookup service.
  • Do not use remote modes if you do not want your browser to contact Modrinth or third-party file hosts.
  • Use the Analytics settings control, browser privacy controls, or a content blocker to limit analytics requests.
  • Close the page after conversion to release in-memory file data; downloaded output remains wherever your browser saved it.
  • Use the help email link only if you want to contact the maintainer; review the message and attachments in your email app before sending.
